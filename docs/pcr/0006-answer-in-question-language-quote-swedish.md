# PCR-0006: Answer in the question's language, quote Swedish sources verbatim

**Decision:** User-facing answers MUST be written in the language of the question, Swedish or English, and in English when the question is in any other language; quoted Swedish source text MUST appear verbatim, followed by an English translation in an English answer.

**Reason:** English-only answers were the earlier rule and lost: the service has Swedish users as well as English ones, and answering a Swedish question in English shuts out the users the service is built for. Translating quotes without the original was also rejected: the sources are Swedish law and plans, and only the verbatim wording can be checked against the source and cited.

**Consequence:** Every answer-producing path decides the question's language and writes the answer, its headings and any follow-up question in it. No path may hardcode an answer language. A quote that is paraphrased, shortened or translated without its Swedish original is a breach, in either language.

**Date:** 2026-11-07
